\section{Artifact Map}
The frozen run is identified as \texttt{exp\_1785360132042\_p113}. The public evidence package includes:
\begin{itemize}[leftmargin=*]
    \item \texttt{config.json}: byte-preserved historical configuration;
    \item \texttt{experiment\_manifest.json}: environment, architecture, completion status, and checkpoint registry;
    \item \texttt{training\_timeseries.json}: measured losses, accuracies, and weight norms;
    \item \texttt{grokking\_event\_detection.json}: milestone outputs and run-level status;
    \item \texttt{checkpoint\_replay\_report.json}: replay measurements from new forward passes;
    \item \texttt{SHA256SUMS}: published package integrity checks;
    \item \texttt{artifact\_index.json}: metadata distinguishing original, derived, and publication artifacts.
\end{itemize}

\section{Checkpoint Roles}
The release preserves checkpoints at five semantically distinct points:
\begin{enumerate}[leftmargin=*]
    \item step 0: initialization;
    \item step 200: memorization;
    \item step 25{,}600: first logged validation threshold crossing;
    \item step 26{,}500: stable validation plateau under the ten-check rule;
    \item step 40{,}000: final model state.
\end{enumerate}

Each checkpoint has a recorded SHA-256 value and a replay status in the experiment manifest.

\section{Reproduction Commands}
Artifact verification:
\begin{verbatim}
python scripts/verify_artifacts.py
\end{verbatim}

Checkpoint replay:
\begin{verbatim}
python scripts/replay_checkpoint.py \
  --checkpoint memorization_model_state.pt
python scripts/replay_checkpoint.py \
  --checkpoint final_model_state.pt
\end{verbatim}

Optional long-run reproduction:
\begin{verbatim}
python scripts/run_experiment.py \
  --config configs/p113_seed42_40k.json \
  --output runs/p113_seed42_40k
\end{verbatim}

A successful independent long run should be reported as a new run rather than replacing the frozen historical evidence.
